# Todo List App

A simple Python todo list with checkable tasks.

## Requirements

- Python 3.6+

## How to Run

1. Save the code as `todo_app.py`
2. Run: `python todo_app.py`

## Features

- Add tasks
- Check off completed tasks
- Delete tasks
- Tasks save automatically

## Usage

- Type a task and press Enter to add it
- Click checkboxes to mark tasks complete
- Click × to delete tasks
- Tasks are saved to `todos.json`

That's it!
