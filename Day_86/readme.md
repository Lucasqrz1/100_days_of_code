# ⚡ Typing Speed Test (Tkinter)

A simple desktop app built with **Python** and **Tkinter** to measure typing speed and accuracy.  
It shows a random sentence, tracks your typing in real-time, and calculates **WPM (Words per Minute)**, **accuracy**, and **elapsed time**.

---

## 🚀 Features
- Randomly chosen practice sentences  
- Real-time speed and accuracy tracking  
- Completion popup with final results  
- Reset and new test options  
- Clean GUI made with Tkinter  



## 📦 Requirements
- Python 3.7+  
- Tkinter (bundled with Python by default)  

No external libraries are required.
