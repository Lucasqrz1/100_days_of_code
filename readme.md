# 100 Days of Code — Python (Angela Yu)

Repository: `Lucasqrz1/100_days_of_code`

## Overview

This repo tracks my progress through Dr. Angela Yu’s **100 Days of Code: The Complete Python Pro Bootcamp** on Udemy. The course is divided into sections that gradually advance from Python fundamentals to advanced data science and web development. Each folder contains exercises, notes, and projects.

---

## Quick Start

* Clone: `git clone https://github.com/Lucasqrz1/100_days_of_code`
* Python: 3.10+
* Install deps when a folder provides a `requirements.txt`:

  ```bash
  pip install -r requirements.txt
  ```

## Highlights by Section

### Beginner Section

* Python syntax, variables, and data types
* Control flow (if/else, loops)
* Functions and return values
* Data structures: lists, dictionaries
* Basic projects: calculators, text-based games, simple ciphers

### Intermediate Section

* Functions with arguments and return values
* Object-Oriented Programming (classes, objects, methods)
* Modules, packages, and imports
* GUI apps with `tkinter`
* Turtle graphics projects
* Small games like Snake, Pong, and Quiz apps

### Intermediate+ Section

* File handling and exceptions
* Working with CSV, JSON, and pandas
* API requests and automation with Python
* Web scraping with BeautifulSoup and Selenium
* Automation bots (LinkedIn, Instagram, Twitter)
* Flask basics and small web apps

### Advanced Section

* Advanced Flask: authentication, databases, blog app
* HTML/CSS integration with Python backends
* REST APIs and deployment
* Capstone web projects

### Data Science and Machine Learning Section

* Data manipulation with pandas and NumPy
* Data visualization with Matplotlib, Seaborn, and Plotly
* Dashboards and interactive plots
* Time series, geospatial data, and NLP basics
* Machine learning: supervised and unsupervised
* Model deployment and feature engineering
* Data pipelines, streaming, and big data introductions

### Capstone

* Final end-to-end project combining Python, web, and data skills

## How to Run GUI Projects

Some projects use `tkinter`, `turtle`, or `pygame`. Run with a local Python interpreter. On macOS enable GUI access for your terminal if needed.

---

## Environment

Use per-folder virtualenvs to avoid dependency conflicts:

```bash
python -m venv .venv && source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
```
