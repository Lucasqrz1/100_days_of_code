# Space Invaders Game

A classic arcade-style Space Invaders game built with Python's turtle graphics library.

## Game Description

Control a spaceship and defend against waves of invading enemies! Move left and right to dodge enemies while shooting them down to earn points.

## How to Play

### Controls
- **Left Arrow Key**: Move spaceship left
- **Right Arrow Key**: Move spaceship right  
- **Spacebar**: Fire bullet

### Objective
- Destroy red enemy ships by shooting them
- Avoid colliding with enemies
- Earn 10 points for each enemy destroyed
- Survive as long as possible!

## Game Features

- 6 enemy ships that move in formation
- Enemies drop down and change direction when hitting screen edges
- Single bullet system (one bullet at a time)
- Score tracking system
- Collision detection between player, enemies, and bullets
- Game over when player touches an enemy

## Requirements

- Python 3.x
- turtle module (included with Python)

## How to Run

1. Make sure Python is installed on your system
2. Save the code as `space_invaders.py`
3. Run the game:
   ```
   python space_invaders.py
   ```

## Game Mechanics

- **Player**: White triangle spaceship at bottom of screen
- **Enemies**: Red circles that move horizontally and drop down periodically
- **Bullets**: Yellow projectiles fired from player ship
- **Screen Size**: 800x600 pixels with black background

## Tips

- Time your shots carefully - you can only have one bullet on screen at a time
- Keep moving to avoid enemy collisions
- Enemies speed up the game as they move, so stay alert!
