# Portfolio Website

A modern, responsive personal portfolio website with social media integration.

## What This Is

Think of this as your professional online home - a place where people can learn about you, see your work, and easily connect with you on LinkedIn, GitHub, or via email.

## Features

- **Responsive Design** - Looks great on phones, tablets, and computers
- **Social Media Links** - Direct connections to LinkedIn and GitHub
- **Contact Form** - Visitors can send you messages directly
- **Smooth Animations** - Professional floating and hover effects
- **Modern Styling** - Clean, professional appearance with gradients

## How to Use

### 1. Customize Your Information
Replace these placeholders with your real details:

```html
<!-- In the HTML file, update these: -->
- "Your Name" → Your actual name
- "your-profile" → Your LinkedIn username
- "your-username" → Your GitHub username  
- "your.email@example.com" → Your real email
```

### 2. Add Your Photo
Replace the placeholder image URL:
```html
<img src="https://via.placeholder.com/300x200/667eea/ffffff?text=Your+Photo" 
     alt="About me">
```

### 3. Update Your Content
- **About Me section** - Write your personal introduction
- **Skills section** - List your technical abilities
- **Projects section** - Showcase your best work

### 4. Deploy Your Site
You can host this website on:
- GitHub Pages (free)
- Netlify (free)
- Vercel (free)
- Any web hosting service

## Technologies Used

- HTML5
- CSS3 (with animations and gradients)
- JavaScript (for interactivity)
- No external dependencies - works offline!

## Quick Start

1. Download the HTML file
2. Open it in a text editor
3. Replace placeholder text with your information
4. Open in a web browser to preview
5. Upload to your hosting service

## Contact Form

The contact form currently shows an alert message. To make it fully functional, you'll need to:
- Connect it to a backend service (like Formspree or Netlify Forms)
- Or integrate with email services

## Browser Support

Works on all modern browsers including Chrome, Firefox, Safari, and Edge.
